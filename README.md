## 화면 구성

- **상단 툴바**: 새 파일 / 디렉토리 / 열기 / 저장 / HTML 내보내기 버튼 + 현재 파일 경로 표시(미저장 시 ● 표시)
  - 파일 경로 클릭 시 탐색기가 열리고 해당 파일이 선택됨
- **좌측 디렉토리 패널** (`🗂️ 디렉토리` 버튼으로 열고 닫음)
  - 열린 파일이 있으면 그 파일 위치, 없으면 홈 디렉토리가 기본 표시
  - 상단에 모든 드라이브(C:, D:, …) 버튼 고정 표시, 클릭으로 바로 이동
  - 폴더 한 번 클릭 → 이동, md 파일 더블 클릭 → 열기
  - 닫았다 다시 열면 마지막 탐색 위치 유지
- **좌측**: 마크다운 원본 편집기 (다크 테마)
- **우측**: 실시간 렌더링 미리보기 (키를 뗄 때마다 즉시 갱신, 마우스 드래그로 텍스트 선택/복사 가능)
- **하단 상태바**: 커서 위치(줄:칸), 글자 수, 저장 알림
- 가운데 세로 막대를 드래그하면 좌우 비율 조절

## 기능

| 기능 | 방법 |
|------|------|
| 화면 확대/축소 | 툴바 우측 끝 `−` / `+` 버튼 또는 `Ctrl+마우스 휠` — 편집기와 미리보기 동시, 50~200%, 배율 클릭 시 100% |
| 미리보기 테마 | `⚙️ 설정 → 기본 설정 → 미리보기 테마`: 글래스모피즘 / 브루탈리즘 / 모던 / 레거시 — Mermaid 다이어그램과 표의 모양을 함께 변경 |
| 파일 메뉴 | 상단 `📁 파일` 드롭다운에 열기/다른 이름 저장/모두 저장/모두 닫기 그룹화 |
| 파일 열기 | `📁 파일 → 📂 열기` 또는 `Ctrl+O` (여러 파일 = 탭으로 열림) |
| 저장 (원본 md에 저장) | 상단 `💾 저장` 버튼(🔍 검색 왼쪽) 또는 `Ctrl+S` — Confluence 문서는 Confluence에, 로컬 파일은 로컬에 저장 |
| 다른 이름으로 저장 | `📁 파일 → 📝 다른 이름 저장` 또는 `Ctrl+Shift+S` |
| 모두 저장 | `📁 파일 → 🗃️ 모두 저장` — 확인 후 열린 탭 전체 일괄 저장 |
| 모두 닫기 | `📁 파일 → 🚪 모두 닫기` — 확인 후 닫기(변경사항 있는 파일마다 저장 여부 확인) |
| 새 문서 | `📄 새 파일` 버튼 또는 `Ctrl+N` |
| 검색 | `🔍 검색` 버튼 또는 `Ctrl+F` — **프로그램 상단 중앙에 뜨는 검색 바**로 에디터/미리보기 동시 하이라이트·이동, **전체보기(에디터 전용/미리보기 전용) 상태에서도 사용 가능** |
| Mermaid 다이어그램 | ```` ```mermaid ```` 코드 블록을 **미리보기·웹에디터에서 다이어그램(SVG)으로 표시**(flowchart·sequence·class·state·ER·gantt·pie 등, 오프라인 동작, 글래스모피즘 테마) |
| HTML 내보내기 | `🌐 HTML 내보내기` — 미리보기와 동일한 스타일의 단일 html 파일 생성 |
| 설정 | `⚙️ 설정` — 좌측 메뉴(기본 설정 / Confluence 연결). 기본 설정에서 백업 폴더 지정 |
| 자동 백업 | 백업 폴더 지정 시 저장할 때마다 `파일명_년월일시분초` 사본을 원본 경로 구조로 백업 |
| Confluence 연동 | 연동 완료 시 `🔗 Confluence 조회` 메뉴 노출 — 문서 목록 조회·열기·편집·저장(업데이트), `☁️ Confluence 업로드`로 새 페이지 생성 |
| 설명서 | `❓ 설명서` — 프로그램 사용법 / 마크다운 문법 30선 / 버전 기록 (모달, 검색 지원) |
| 언어 전환 | 우측 상단 `KOR / ENG` 버튼 — 메뉴·설명·안내 전체를 한/영으로 전환(설정 저장) |
| 파일 관리 | 디렉토리 패널에서 우클릭(열기·이름 변경·삭제·새 파일·새 폴더 — 생성 직후 바로 이름 변경), **폴더 삭제 가능**, 파일/폴더 드래그로 다른 폴더 이동 |
| 다중 선택 | 파일 다중 선택(드래그 러버밴드 · `Ctrl`/`⌘`+클릭 · `Shift`+범위) 후 우클릭 → **열기(N개) 동시 열기** / 삭제(N개). 폴더는 선택 제외 |
| 드래그 앤 드롭 | 탐색기(Windows)/Finder(macOS)에서 파일을 드롭하면 원본 경로로 열림(파일명·경로 표시, 저장 시 원본 업데이트+백업) |
| 파일 정보 | 에디터 상단에 현재 파일의 최초 생성일 / 최근 수정일 표시 |
| 파일명 표시 | 편집기 · 웹에디터 · 미리보기 상단에 현재 열린 파일명 표시(📄) — 이미 열린 파일은 중복 없이 해당 탭으로 이동 |
| 동기 스크롤 | 좌/우 어느 쪽을 스크롤해도 반대편이 비율 기준으로 동기 이동 |
| 탭별 위치 기억 | 탭을 오가면 각 파일에서 **마지막으로 보던 커서·스크롤 위치로 복귀**(편집창 포커스), 새로 연 파일은 맨 위 |
| 커서 위치 표시 | 미리보기 · 마크다운 편집창 · 웹에디터 우측 하단에 **원문(md) 기준 `줄 N, 칸 M`** 을 같은 값으로 표시 |
| 파일 탭 | 탭 클릭 = 전환(디스크 변경 시 재로딩 확인), 드래그 = 순서 변경, ◀▶ = 한 탭씩 이동, ✕ = 닫기, **탭 우클릭 = 💾 저장 / 🔄 새로고침 / ✕ 닫기 메뉴** |
| 디렉토리 패널 | 폴더/`..` 한 번 클릭 = 이동, 파일 더블클릭 = 열기(숨김·모든 파일 표시), 경계선 드래그 = 너비 조절, 상단 **🔄 새로고침** 버튼으로 목록 갱신 |
| 맨 위로 | 에디터/미리보기 우측 하단의 ▲ 버튼 |
| 전체보기 | MARKDOWN/PREVIEW 라벨 옆 ⛶ 버튼으로 해당 영역만 전체 표시 |

> 🖥️ **단축키**: Windows/Linux는 `Ctrl`, **macOS는 `⌘(Command)`** 를 사용합니다. (예: 저장 = `Ctrl+S` / `⌘+S`)

지원 문법: 표, 펜스 코드블록(문법 하이라이트), 체크박스 목록, 취소선(`~~`),
하이라이트(`==텍스트==`), 각주, admonition(`!!! note`), **Mermaid 다이어그램**(```` ```mermaid ````) 등.

파일 인코딩: UTF-8 / UTF-8(BOM) / CP949(EUC-KR) 자동 인식, 저장은 UTF-8.

## 🚀 자동 업데이트

앱을 시작하면 **릴리스 전용 저장소** [jm-markdowneditor-release](https://github.com/wbslog/jm-markdowneditor-release)의
GitHub Releases에서 새 버전을 자동 확인합니다 (v1.30.0부터. 소스 코드는 이 저장소, 배포 파일은 릴리스 저장소).

- 새 버전이 있으면 **안내창**이 뜨고, **다운로드 및 재시작**을 누르면 OS에 맞는 릴리스 파일을
  **기존 프로그램이 있는 폴더에 내려받은 뒤** 기존 앱을 종료하고 새 파일을 자동 실행합니다.
- 새 버전을 처음 실행하면 **추가/개선 내용**(릴리스에 작성한 메시지)이 안내창으로 표시됩니다.
  **다시 보지 않기**를 체크하면 이후 버전에서도 표시되지 않습니다.

> **릴리스 올릴 때 규칙** (자동 업데이트가 인식하려면):
> - 태그: `v1.7.0` 형식 (`v` + 버전)
> - 파일명: Windows는 `...exe`, macOS는 이름에 `mac`이 들어간 `...zip` (예: `jm-mdv-1.7.0.exe`, `jm-mdv-1.7.0-mac-arm64.zip`)
> - **릴리스 설명(body)** 에 적은 내용이 "새로운 기능" 안내창에 그대로 표시됩니다 (마크다운 지원)

## 💾 자동 백업

**⚙️ 설정 → 기본 설정 → 백업 파일 저장 경로**에서 백업 폴더를 지정하면, 파일을 저장할 때마다
원본은 원래 위치에 그대로 업데이트되고, **별도의 백업 사본**이 다음 규칙으로 생성됩니다.

- 파일명: `원본이름_YYYYMMDDHHMMSS.확장자` (예: `note_20260708153012.md`)
- 위치: 백업 폴더 아래에 **원본 경로 구조를 그대로 재현**하여 저장
  (예: 원본이 `X:\docs\note.md`, 백업 폴더가 `D:\bak` → `D:\bak\X\docs\note_...md`)
- 백업 폴더를 지정하지 않으면 백업 사본은 만들지 않습니다.

## 🔗 Confluence 연동

Confluence Cloud 문서(특정 **폴더** 하위)를 앱에서 바로 열고 편집·저장·삭제할 수 있습니다.
커스텀 도메인(사내 위키 등) 뒤의 Confluence Cloud도 **cloudId 게이트웨이**(`api.atlassian.com/ex/confluence/{cloudId}`)로 호출하여 동작합니다.

1. **API 토큰 발급** — 아래 두 가지 방법 중 하나로 발급합니다. (스코프 없는 **클래식 토큰** 권장)

   **방법 A — 직접 링크(가장 빠름)**
   1. 브라우저에서 [id.atlassian.com/manage-profile/security/api-tokens](https://id.atlassian.com/manage-profile/security/api-tokens) 접속 후 Atlassian 계정으로 로그인
   2. **Create API token (API 토큰 만들기)** 버튼 클릭
      - "Create API token with scopes"가 아닌 **일반 Create API token**을 선택하세요 (스코프형은 권한 부족으로 403이 날 수 있음)
   3. **Label (라벨/토큰 이름)** 입력 → **Create (만들기)**
   4. 표시된 토큰 문자열을 **즉시 복사** — ⚠️ 창을 닫으면 다시 볼 수 없습니다
   5. 복사한 값을 앱 설정의 **토큰 값** 칸에 붙여넣기

   **방법 B — Confluence 화면에서 찾아가기**
   1. Confluence 우측 상단 **프로필 아이콘(내 사진)** 클릭
   2. **Manage account (계정 관리)** 클릭 → Atlassian 계정 페이지로 이동
   3. 상단 탭에서 **Security (보안)** 클릭
   4. **API tokens (API 토큰)** 항목의 **Create and manage API tokens (API 토큰 만들기 및 관리)** 클릭
   5. 이후는 방법 A의 2~5단계와 동일
2. 앱 상단 **⚙️ 설정 → Confluence 연결**을 열고 아래 4개를 입력합니다.
   - **로그인 아이디(email)**: 토큰을 만든 Atlassian 계정 이메일
   - **토큰 이름**: 라벨(식별용, 인증엔 미사용)
   - **토큰 값**: 발급한 API 토큰
   - **접근할 폴더 링크**: 대상 폴더 URL
     (예: `https://사이트/wiki/spaces/KEY/folder/466190962`, 스페이스 링크도 가능)
3. **🔌 연동 테스트**로 폴더 접근을 확인한 뒤 **저장**합니다. (cloudId는 자동 조회·저장)
4. 연동이 완료되면 상단에 **🔗 Confluence** 메뉴가 나타납니다.
   - 폴더 하위 문서 목록을 조회하고, 클릭해 열어 편집한 뒤 `Ctrl+S`(macOS는 `⌘+S`)로 **업데이트**(버전 자동 +1)합니다.
   - 새 문서는 **"현재 내용을 새 페이지로 저장"**으로 제목을 입력해 생성(v1 우선·v2 폴백)합니다.
   - 목록의 🗑️ 버튼으로 페이지를 **삭제(휴지통 이동, 복구 가능)** 합니다.

> 편집 왕복(round-trip)을 위해 원본 마크다운을 페이지의 content property로 함께 보존합니다.
> 설정값(토큰 포함)은 사용자 홈의 `.jm-mdv-confluence.json`에 로컬 저장됩니다.
> 설정값은 사용자 홈의 `.jm-mdv-confluence.json`에 저장됩니다(토큰 포함, 로컬 저장).

## 📥 다운로드 후 실행 (릴리스 사용자용)

[릴리스 저장소의 GitHub Releases](https://github.com/wbslog/jm-markdowneditor-release/releases)에서 자신의 OS에 맞는 파일을 받아 실행합니다.
고정 다운로드 주소: <https://github.com/wbslog/jm-markdowneditor-release/releases/latest/download/jm-mdv.exe>
직접 빌드하지 않고 바로 쓰고 싶은 분은 이 방법을 사용하세요.

### 🪟 Windows

1. 릴리스에서 **`jm-mdv.exe`** (또는 `jm-mdv-win.zip`)를 받습니다. zip이면 압축을 풉니다.
2. `jm-mdv.exe`를 더블클릭해 실행합니다.
3. **"Windows의 PC 보호"(SmartScreen)** 경고가 뜨면 → **추가 정보** → **실행**을 누릅니다.
   (서명이 없는 앱이라 나오는 정상 경고이며, 최초 1회만 확인하면 됩니다.)

### 🍎 macOS — 원클릭 설치 · 업데이트 (누구나 가능, 권장)

> ⚠️ **릴리스에는 macOS용 파일이 없습니다.** 맥은 직접 빌드해야 하지만,
> 아래 **한 줄**만 붙여넣으면 다운로드부터 빌드·설치·실행까지 전부 자동으로 됩니다.
> **IT 지식이 없어도 됩니다** — 복사, 붙여넣기, Enter가 전부입니다.

1. **터미널 열기**: 키보드에서 `⌘(Command) + Space` → `터미널` 입력 → Enter
2. 아래 한 줄을 **복사해서 터미널에 붙여넣고 Enter**:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/wbslog/jm-markdowneditor/main/easy_mac_setup.sh | bash
   ```
3. 끝! 몇 분 뒤 앱이 자동으로 실행되고, **응용 프로그램(Launchpad)에 `jm-mdv`** 가 설치됩니다.

- **최초 1회**, "명령어 도구(Command Line Tools) 설치" 창이 뜰 수 있습니다 → **[설치]** 클릭 후
  설치가 끝나면 **위의 한 줄을 한 번 더** 실행해 주세요. (Apple 공식 도구입니다)
- **업데이트도 똑같습니다** — 새 버전이 나오면 위 한 줄을 다시 실행하면 최신 버전으로 교체됩니다.
- 스크립트가 하는 일: 소스 다운로드(`~/jm-mdv-src`) → 가상환경에 패키지 설치(시스템은 건드리지 않음)
  → 앱 빌드 → `응용 프로그램` 폴더에 복사 → 보안 격리 해제(`xattr`) → 실행

> **실행이 안 될 때** — 터미널에서 직접 실행하면 실제 오류가 표시됩니다:
> ```bash
> /Applications/jm-mdv.app/Contents/MacOS/jm-mdv
> ```
> - `developer cannot be verified` / "손상됨" → `xattr -cr /Applications/jm-mdv.app` 후 재시도
> - 그 외 오류는 위 한 줄 명령을 다시 실행하면 처음부터 깨끗하게 다시 빌드합니다.

#### 🔄 macOS 업데이트 방법 (앱 내 안내)

macOS는 코드 서명/공증이 없어 **자동 교체를 하지 않습니다.** 새 버전이 있으면 앱의 **🚀 업데이트** 창에 아래 안내와 버튼이 표시됩니다.

- **간단(권장)**: 터미널에 위의 **원클릭 한 줄**을 다시 붙여넣기 → 자동으로 최신 버전 재빌드·교체
- **수동(개발자)**: `🛠 빌드 가이드(README) 열기` 버튼 → `git pull` → 가상환경/패키지 → `pyinstaller` 빌드

> Windows는 종전대로 **⬇️ 다운로드 및 재시작** 으로 자동 업데이트됩니다.
